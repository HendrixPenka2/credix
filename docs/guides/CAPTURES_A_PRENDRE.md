# Captures d'écran : état des lieux

**Outil de travail de l'auteur : ce fichier n'est pas à envoyer à l'encadrant.**

## Principe

Une image n'apparaît dans un PDF que **si son fichier existe**. Aux endroits où il n'y a pas d'image, le texte reste et décrit chaque étape : rien ne manque dans les documents.

Pour **ajouter** une image plus tard : déposer le PNG dans `docs/images/guides/` (ou `docs/images/readme/`), ajouter sa ligne dans le fichier Markdown (guide 4, section 8.3), puis lancer `docs/build/build_all.sh`.
